### 👨‍💻 Sobre Mim & Filosofia de Engenharia

Engenheiro de Software Sênior e **Tech Lead** especializado na concepção, arquitetura e escala de **plataformas SaaS corporativas** e ecossistemas de **Agentes Autônomos de Inteligência Artificial**.

Possuo sólida experiência em todo o ciclo de vida de produtos digitais — desde a modelagem de microsserviços distribuídos e pipelines GraphQL de baixa latência até aplicações web reativas e apps móveis de missão crítica. Minha atuação é guiada pela busca de **eficiência computacional**, **segurança defensiva rigorosa** e **otimização de custos e performance** para os usuários finais e clientes corporativos.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ ✦ Pilares de Atuação Técnica:                                               │
│                                                                             │
│ 1. Arquitetura SaaS Enterprise   → Multi-tenant, GraphQL, resiliência       │
│ 2. Engenharia de Agentes & IA    → MCP, CodeGraph AST, memórias semânticas  │
│ 3. Performance & Economia        → Profiling, menor uso de tokens, caching  │
│ 4. Segurança Rigorosa & Shift-Left → Análise estática, compliance & auth     │
```
